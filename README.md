# CareerConnect – Jobs and Internship Management System

## About the Project

CareerConnect is a front-end web application developed to help students explore job and internship opportunities, save interesting listings, and manage their application status in one place.

The project provides a simple interface where students can view opportunities, save jobs for later, and track their progress.

## Features

- **Job Listings:** View available sample job and internship opportunities.
- **Search:** Search for opportunities using keywords.
- **Save Jobs:** Save interesting opportunities for later.
- **Application Tracker:** Manage application status, such as Interested and Applied.
- **Data Persistence:** Store saved jobs and application information using browser localStorage.
- **User-Friendly Interface:** Simple and easy-to-use design.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run the Project

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open the project folder in Visual Studio Code.
4. Open `index.html` in your browser or run it using the Live Server extension.
5. Explore the job listings, save jobs, and update application statuses.

## Working of the Project

HTML is used to create the structure of the website. CSS is used to design the layout and improve its appearance. JavaScript handles interactions such as saving jobs and updating application statuses. Browser localStorage stores supported information so that it remains available after refreshing the page in the same browser.

## Limitations

- The project is currently a front-end application.
- It does not include a backend, database, or user authentication.
- Job and internship listings are sample data, not verified live vacancies.
- Saved data is stored locally in the browser and is not synchronized across devices.
- Search functionality requires testing to ensure it works correctly for all relevant keywords.
